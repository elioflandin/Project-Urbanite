void _timer_pwm_config ( uint32_t  display_id)

Configure the timer that generates PWM signals for the RGB display.

This function sets up TIM4 in PWM mode 1 at 50 Hz for channels 1 (Red), 3 (Green), and 4 (Blue). It is only configured for PORT_REAR_PARKING_DISPLAY_ID.

Parameters
display_idDisplay system identifier.

◆ port_display_init()

void port_display_init ( uint32_t  display_id)

Initialize the hardware configuration of a given RGB LED display.

Initializes the hardware configuration of the specified RGB display.

This function configures the GPIOs and alternate functions of the three RGB pins. It also initializes the PWM timer and turns the LED off by default.

Parameters
display_idDisplay system identifier (e.g., PORT_REAR_PARKING_DISPLAY_ID)

Set the RGB LED display to the specified color using PWM.

Updates the color of the specified RGB display.

This function disables the PWM timer, sets the duty cycle of each LED color based on the rgb_color_t values, and re-enables the timer.
